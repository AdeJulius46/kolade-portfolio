# Kolade Ogunleye portfolio

Next.js (App Router) portfolio for Kolade Ogunleye, Data Analyst / Data Scientist.

## Run locally
npm install
npm run dev        # http://localhost:3000

## Deploy
Push to GitHub and import into Vercel (zero config), or run `npm run build && npm start`.

## Edit content
- Copy, projects, skills, links: app/page.tsx
- Dashboard tabs: app/DashboardViewer.tsx (images in public/taxi-*.webp)
- Colours and type: app/globals.css (:root tokens)
